Notes:
- Screens 01 and 04–08 show the tracker's **demo mode** (orange "Demo data" banner, "Exit demo" button). The app does not need a demo banner unless Colby asks; ignore it.
- In demo mode editing is off, so screen 08 shows "Needs someone with edit access" where the deck height buttons ("Set at 2.00 m" / "Set at 1.70 m") normally appear. Build the buttons.
- The floating blue **Log** button and bottom tab bar are fixed on screen in the real app; in these full-page captures they are drawn at the bottom of the page.
- The design canvas on claude.ai was generated from these same screens, so it adds nothing beyond these images.
