# Stevedoring & VSA Glossary: Colonels Island, Brunswick GA
Version 1.2 · Compiled 2026-09-24 (v1.1: operator names confirmed; v1.2 2026-10-05: Appendix D zone correction, Yard 3 wording) · Owner: Colby

**How to read the Status column** (it follows the VSA fact-classification rule):
- **Confirmed**: stated by Colby, or part of the VSA Operating Protocol. Authoritative.
- **Industry**: standard ro-ro/port usage. Verify that local usage matches before relying on it.
- **Needs definition**: the term is in use but its meaning isn't recorded yet. Do not guess it.

Colby's current direct instruction and the official SOPs outrank this glossary.

## 2. Operations & documents

| Term | Meaning | Status |
|---|---|---|
| Ro-Ro | Roll-on/roll-off: cargo is driven on and off the vessel | Industry |
| PCTC / PCC | Pure Car & Truck Carrier / Pure Car Carrier, the vessel types for vehicle cargo | Industry |
| Discharge | Unloading units from the vessel to the terminal | Confirmed |
| Load-back | Loading units from the terminal onto the vessel | Confirmed |
| H&H (High & Heavy) | Oversized rolling or static cargo such as construction and agricultural equipment. Kept **separate** from automobile data analysis | Confirmed |
| BEV | Battery Electric Vehicle; cargo with its own handling requirements | Confirmed |
| Unit | One vehicle or piece of cargo | Industry |
| Load list | Document listing the units to load. **Authoritative on quantity** over the game plan unless explicitly overridden | Confirmed |
| Game plan | The operational plan for a vessel job | Confirmed |
| Stow plan | Vessel plan showing where cargo sits, by deck | Industry |
| Deck clearance | Vertical height limit of a vessel deck; checked against vehicle height | Confirmed |
| Lashing | Securing units to the deck for the voyage | Industry |
| Ramp | Vessel ramp used for driving units on and off | Industry |
| VIN | Vehicle Identification Number | Industry |
| Tally / Checker | Unit count record, and the person who keeps it | Industry |
| Forecast vs. actual | VSA tracking of projected production against recorded production | Confirmed |
| Hourly update | Hourly production report. Always subtract it from the total and state the **remaining** count | Confirmed |
| TICO shuttle van | Port shuttle vans run by TICO, tracked on the TICO Check In/Out sheet | Confirmed |

## 3. Time, breaks & production

| Term | Meaning | Status |
|---|---|---|
| 5-hour break rule | Applies to **every** ship, for both discharge and load-back | Confirmed |
| Breaks | **12:00** and **18:00** | Confirmed |
| Short hours | 11:00–12:00 and 17:00–18:00. Expect a production dip | Confirmed |
| Pre-break cutoff | Stop work before a break: Southside at 11:30 / 17:30; Northside at 11:45 / 17:45 | Confirmed |
| 07:00 start | Includes a 10-minute safety meeting | Confirmed |
| Template times | The VSA template records start, break, and end times only. Break policy lives in the knowledge base | Confirmed |
