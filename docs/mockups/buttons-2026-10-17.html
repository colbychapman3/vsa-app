Decisions (recommended answer in bold)

  1. Three button kinds only (primary peach, secondary white, danger red), all pill-shaped, 52 tall (44 for small inline ones like Now), with the same navy 2 pt edge. No shadows on any button. The blue fill goes away.
  2. At most one peach button per screen. "Export vessel log" stays peach on Backup; Import and Save photos become white.
  3. "Go to" buttons (white with ›) replace the row-cards ("Break or end of shift") and the blue text links ("Completion report notes ›", "Fewer hours").
  4. Choices (Log tabs, status, hours, deck grid): pill, thin grey edge, picked = navy, one text size for every label (nothing shrinks to fit; a long label wraps between words).
  5. Shorter words: "Save deck", "Export log", "Import log", "Save photos", "Skipped (still aboard)", "blank = unknown". Longer explanations move behind (i). Data-honesty wording stays (unknown is still said, just shorter).
  6. The same rules in Night and Extra visible (the edge uses the theme's ink color; Extra visible keeps its heavier edges).
  7. Scope: one shared button style in ui.tsx, then a sweep of the ~86 hand-made buttons on the screens to use it. JS only, so it ships as an over-the-air update after the harness check.
